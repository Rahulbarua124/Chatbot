
# 🌿 FASAL: Echo Chamber - AI Crop Care Assistant

An AI-powered assistant that detects plant diseases, pests, and water stress from images using CNN, powered by Flask + React.

## 👨‍🌾 Features
- Disease/Pest/Water stress detection via image
- React frontend for farmers
- Flask backend with TensorFlow model

## 🚀 Run Locally
1. Train model: `python model_training/train_model.py`
2. Start backend: `cd backend && python app.py`
3. Start frontend: `cd frontend && npm start`

## 💻 Stack
- ML: TensorFlow/Keras
- Backend: Flask
- Frontend: React
